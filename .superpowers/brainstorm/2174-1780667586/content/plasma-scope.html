Where should the plasma animation run?

The animated WebGL background is eye-catching but GPU-intensive. Choose where it appears.

A

Sign-in page only

Full plasma animation on the sign-in page — a dramatic first impression. Dashboard and editor use a static indigo/purple gradient background instead. Fastest, most performant.

B

Sign-in + Dashboard header

Sign-in gets full plasma. The dashboard shows plasma as a subtle hero strip at the top (behind the navbar and title), fading into a clean white content area below. Editor uses a static gradient.

C

All pages — full plasma everywhere

Every page runs the plasma animation. Uses more GPU. Best visual consistency.
