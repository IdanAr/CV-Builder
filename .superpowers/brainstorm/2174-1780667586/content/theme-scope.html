Where should the theme apply?

The indigo/purple SaaS theme has three surfaces in your app. Pick how far it should spread.

A

Full app — all pages

Sign-in page, dashboard (navbar + cards + backgrounds), and the editor shell all adopt the indigo/purple palette, glassmorphic elements, and gradient accents. The editor canvas (the CV preview itself) stays white — that's always a clean paper mock.

B

Marketing surfaces only — sign-in + dashboard

Sign-in page and dashboard get the full treatment (glassmorphic navbar, gradient backgrounds, styled cards). The editor stays clean and minimal so it doesn't distract from CV content.

C

Accent-only — palette everywhere, no plasma background

All pages adopt the indigo/purple colour palette, typography and button styles. No animated plasma background or frosted-glass effects — keeps it lighter and faster on lower-end hardware.
