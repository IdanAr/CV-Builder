Key architectural decisions baked in

  • Route groups — (auth) and (dashboard) share separate layouts; no auth layout leaks into the dashboard shell
  • Zod is the single validation point — Mongoose schemas are derived from Zod, not the other way around. Types flow from Zod → TypeScript → Mongoose.
  • Middleware guards all dashboard + API routes — unauthenticated requests are redirected at the edge before any handler runs
  • MongoDB connection pooled in lib/db.ts — singleton pattern to survive serverless cold starts across route calls
