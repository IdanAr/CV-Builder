Implementation notes for the new features

Metadata row — createdAt and updatedAt come from MongoDB timestamps (enabled on the Mongoose schema). Sections filled = count of non-empty top-level arrays in data (work, education, skills, etc.), computed server-side and returned with the list endpoint. Layout comes from meta.layout. ATS Score field is rendered as a placeholder now; populated in Phase 3.
⬇ JSON download — Phase 1 only. Client-side: fetch GET /api/resumes/[id], serialize data to a Blob, trigger <a download>. No new API endpoint needed. PDF/DOCX download added in Phase 2 — the button becomes a dropdown (JSON / PDF / DOCX) at that point.
⧉ Duplicate — new API endpoint: POST /api/resumes/[id]/duplicate. Server copies data and meta, sets title to "Copy of [original title]", assigns the same userId, returns the new document. Dashboard immediately appends it to the list.
