A1

Two-panel with ↑↓ and → ← per column

Full column-aware reorder. Each column is its own independent ordered list with its own up/down controls. The cross-over arrow moves a section to the end of the other column. Reordering in Edit tab updates too.

A2

Flat list with clickable LEFT/RIGHT badge

One flat list keeps the section order. The badge toggles the column assignment. Drag handle still works for global reorder. Simple, compact, no extra panel space needed.
