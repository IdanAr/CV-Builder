Column Assignment UI — Which Approach?

When "Two Columns" layout is active, users need a way to move sections between left/right columns. Here are 3 options.

A — Visual Two-Column Editor

Design panel shows both columns side-by-side. Each section has an arrow button to cross over. Appears only when two-column layout is active.

Pros

  • Matches the actual CV layout — no mental mapping
  • Immediately obvious which side each section is on

Cons

  • Wider panel needed (or tighter layout)

B — L/R Toggle in Section List

The section order list (Edit tab) gets an L/R pill toggle per row — visible only in two-column mode. Drag to reorder within a column, toggle to switch sides.

Pros

  • Reorder + column in one place
  • Compact — no extra panel space

Cons

  • L/R labels less intuitive than visual columns
  • Two-column UI buried in Edit tab

C — Drag-and-Drop Between Columns

A visual drag-and-drop area with two droppable columns. Drag sections between columns and also reorder within each column. Most spatially intuitive.

Pros

  • Most intuitive for spatial thinkers
  • Reorder + reassign in one gesture

Cons

  • Most complex to implement
  • Drag-and-drop can feel heavy on a settings panel
